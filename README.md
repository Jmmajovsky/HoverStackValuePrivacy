Hover Stack Value Privacy Policy
Oct 20, 2026 · @Jake
Who we are
Hover Stack Value is a RuneScape client plugin made by Majjac Plugins, an independent developer. It is not made or endorsed by Jagex.
For any privacy question or request, email majjacplugins@gmail.com.
In short
The only thing the plugin sends anywhere is the ID number of an item you hover over, to look up its Grand Exchange price. As with any web request, the server that answers also sees your IP address.
The plugin does not send or collect your account name, character name, chat, bank contents, location or anything else about you. The developer receives none of this information.
What the plugin uses on your device
To work out a stack's value, the plugin reads this from the game client while you hover an item:
• the item's ID, name and stack size
• the item's store value and alchemy settings from the game's item data
• which interface the item is in (for example the bank or backpack)
This stays on your device. Looked-up prices are kept in memory for up to 30 minutes and are cleared when the plugin stops.
The only thing the plugin saves between sessions is its own display settings (where the value box appears and which hold key it uses). These are stored by the game client on your device and are never sent anywhere.
What leaves your device, and why
The game doesn't give plugins Grand Exchange prices, so the plugin looks them up online. The first time you hover an item that can be traded on the Grand Exchange, it requests that item's price over an encrypted (HTTPS) connection.

Who receives it
Price requests go to the RuneScape Wiki's price service at api.weirdgloop.org, run by Weird Gloop USA, Inc., the company that operates the RuneScape Wiki. Weird Gloop uses Cloudflare to deliver its service, so requests pass through Cloudflare's network first.
Both companies are based in the United States, which does not have UK adequacy status. The information is protected in transit by HTTPS encryption, and it is limited to an item ID and your IP address. Weird Gloop's handling of it is described in its privacy policy.
The developer of Hover Stack Value does not receive, see or store any of this information.
Lawful basis
The plugin relies on legitimate interests: when you install and enable it, you ask it to show item values, and looking up prices is the only way to do that. Only the minimum is sent (an item ID), and nothing is used for any other purpose, such as advertising or tracking.
If you don't want any price requests made, disable the plugin or remove its permission in the Plugin Hub.
How long it's kept
• By the developer: nothing is kept, because nothing is received.
• By the plugin on your device: looked-up prices for up to 30 minutes, in memory only; your display settings until you change them or remove the plugin.
• By Weird Gloop: its web servers log visitors' IP addresses, and its privacy policy says most identifiable information is deleted after 90 days.
Your rights
Under UK data protection law you can ask to see, correct or delete your personal data, restrict or object to its use, and receive a copy of it.
• Requests about the plugin: email majjacplugins@gmail.com. The developer holds no personal data about you, but will answer any question and help with any request.
• Requests about Weird Gloop's server logs: contact Weird Gloop at support@weirdgloop.org, as described in its privacy policy.
• Stopping it entirely: disable or remove the plugin in the Plugin Hub, and no further requests are made.
You can also complain to the UK's data protection regulator, the Information Commissioner's Office.
Changes and contact
If the plugin starts using information differently, for example a new price service, this policy will be updated first, with the date at the top changed and the change noted on the plugin's Mod.io page.
Questions about this policy: majjacplugins@gmail.com.
