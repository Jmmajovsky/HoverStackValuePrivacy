# Hover Stack Value Privacy Policy

Oct 24, 2026 · @Jake

## Who we are

Hover Stack Value is a RuneScape client plugin made by Majjac Plugins, an independent developer. It is not made or endorsed by Jagex.

For any privacy question or request, email **majjacplugins@gmail.com**.

## In short

Hover Stack Value doesn't send anything about you anywhere. Everything it reads stays inside the plugin on your device, and the developer receives none of it.

## What the plugin uses on your device

To work out a stack's value, the plugin reads this from the game client while you hover an item:

- the item's ID, name and stack size
- the item's store value and alchemy settings from the game's item data
- which interface the item is in (for example the bank or backpack)
- in shops, where the game only gives plugins the hovered item's name: the items in the inventories the game client currently has loaded (such as the shop's stock, which can include your own backpack, equipment or bank), searched by name to find the item you're hovering

None of this is saved or sent anywhere. The only thing the plugin saves between sessions is its own display settings (where the value box appears, which hold key it uses and how the box's title is written). These are stored by the game client on your device.

## Grand Exchange prices

Hover Stack Value makes no web requests. Its Grand Exchange prices come from the **GE Price Library**, a separate plugin it depends on. The library downloads the RuneScape Wiki's price list for all items in one request and shares it with every plugin that uses it.

That request is the same for every player and doesn't include anything about you or the items you hover. As with any web request, the wiki's servers see the IP address it comes from. The GE Price Library has its own listing on Mod.io, which describes how it handles data.

## Your rights

The developer of Hover Stack Value holds no personal data about you. If you have a question or a request about your data, email **majjacplugins@gmail.com**.

You can also complain to the UK's data protection regulator, the [Information Commissioner's Office](https://ico.org.uk/make-a-complaint/).

## Changes and contact

If the plugin starts using information differently, this policy will be updated first, with the date at the top changed and the change noted on the plugin's Mod.io page.

Questions about this policy: **majjacplugins@gmail.com**.
